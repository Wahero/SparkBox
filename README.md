# SparkBox 靈感收集盒 — 需求采集工具

一個**單文件、零依賴、可離線運作**的需求采集網頁工具。用戶在瀏覽器填寫需求，工具將內容整理為結構化文字或 JSON，由用戶自行複製或下載後發回收集方。

---

## 一、特性

- **純前端、自包含**：單一 HTML 檔案，內聯全部 CSS/JS，無任何外部 CDN、字型或腳本請求，可離線開啟。
- **手機友好**：針對微信內置瀏覽器、iOS Safari、Android Chrome 做過降級處理。
- **合規聲明內建**：填寫前即提示「資料只留存本機、不會自動上傳任何伺服器」。
- **草稿自動保存**：填寫過程自動存入瀏覽器 `localStorage`，中斷後可續填。
- **導出即清草稿**：成功複製 / 下載 / 分享後自動清除本地草稿，避免跨客戶資料串檔。

## 二、資料隱私說明（重要）

本工具**不會將任何填寫內容上傳至伺服器**。

- 程式碼層面經查證：全檔**不含** `fetch`、`XMLHttpRequest`、`WebSocket`、`sendBeacon`、表單 `POST` 或任何上傳邏輯；唯一的 `http` 字串是 SVG 箭頭的 XML 命名空間（`www.w3.org`），不產生網絡請求。
- 用戶填寫的資料只會留存於：
  1. 本機瀏覽器 `localStorage`（草稿，清除快取會消失）；
  2. 用戶主動「複製」的剪貼簿；
  3. 用戶主動「下載」的本機檔案；
  4. 用戶主動「分享」所選的平台（如微信聊天）。

> 託管平台（見下方部署章節）僅提供「網頁程式碼（HTML 本身）」的靜態托管，伺服器無從看見表單內容。可對客戶聲明：「此表填寫內容只會留在您自己裝置，不會落入任何第三方伺服器。」

## 四、終端用戶使用方式

1. 開啟頁面（點擊連結，或在瀏覽器開啟 `index.html`）。
2. 依區塊填寫：基礎信息、現在的做法、最想解決的問題、期望的系統、需確認事項、預算與時間、聯繫方式。
3. 填完點「儲存」導出：
   - 一般手機瀏覽器 → 可「下載 / 存儲到文件」或「複製內容」。
   - 微信內置瀏覽器 → 「下載」會轉為「已複製」，直接貼回微信聊天即可。
4. 將複製的內容或下載的 `.json` 檔發回收集方。

詳細步驟見 **`guide.html`**。

## 五、部署方式

### A. WorkBuddy 靜態託管（已發布）

公開連結：`https://requirement-collect.app.workbuddy.host/`

- 任何人（含微信內置瀏覽器）點擊即開。
- **注意**：此為平台託管連結，政策上不保證永久有效；若專案被下線或刪除，連結即失效。重要長期用途建議改用下方自有託管。

### B. GitHub Pages（自有域名控制）

將本倉庫推至 GitHub 並開啟 Pages，即獲得一條穩定、自主控制的 URL。

### C. 群暉 NAS / 任意靜態空間

本工具為純靜態單檔，可直接放置於 NAS Web Station、Nginx、OSS 等任何靜態托管處，無須後端。

> 無論採用哪種託管，工具本體（`index.html`）始終是同一份自包含檔案，數據流向不變。
